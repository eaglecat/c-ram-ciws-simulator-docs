# Screenshot shot list

All images live in `assets/img/` as JPEG (quality 88) converted from 1920x1080
PNG Game-view captures. They were taken in the Unity editor on 2026-09-17 with
the Ultra graphics preset, render scale 1.0 and the FPS counter off, by a
throwaway editor script that started each example mission through the normal
custom-mission path, locked the player's camera on the nearest enemy and held
fire for a moment before each capture. README.md marks each image with an HTML
comment such as `<!-- screenshot: example-tetris.jpg -->` right above it.

Stand-ins that could be improved with a hand-played capture:

- `example-combined-arms.jpg`: player C-RAM view firing at the T-90s, with
  the M1A1 and the destroyer in the distance (the example's start height was
  fixed for this; see the Pitfalls entry on `getTerrainHeight` in `Init`).
- `example-fpv-operator.jpg`: the drone's own goggles view one second into
  a sortie, with the convoy still at the horizon.
- `example-drone-defense.jpg`: the quadcopters are small at this distance.
- `example-classic-ground2air.jpg`: the jets are only visible as lock boxes.
- `home-gallery.jpg`: assembled from six of the example shots.
- `ui-*.jpg`: crops of the Air Race, C-RAM Golf and Tetris captures.
- `editor-load-paste.jpg` carries one callout, on the paste button; the other
  shots are raw captures.
